# 웹 화면 실행과 검증

## 실행

프론트는 Spring의 `src/main/resources/static`에서 제공하는 HTML·CSS·ES module이다. 별도 프론트 빌드·런타임 라이브러리나 CORS 설정 없이 같은 서버 API를 사용한다. 서버 환경 변수를 설정하고 `./gradlew.bat bootRun` 후 `http://localhost:8080/`을 연다. `.env`를 현재 프로세스에만 읽는 편의 명령은 `./scripts/run-local.ps1`이다. 파일에 있는 값이나 토큰을 출력하지 않는다.

외부 OCR에는 `OPENAI_API_KEY`, `OPENAI_OCR_MODEL`이 필요하고 분석·채팅에는 `OPENAI_CHAT_MODEL`도 명시해야 한다. 모델 미설정·ClamAV 불가·잘못된 파일은 서버 오류를 그대로 안내하며 모의 성공으로 바꾸지 않는다. Spring은 `.env`를 자동으로 읽지 않는다. PostgreSQL·ClamAV 실행 및 비밀 설정 방법은 README를 따른다.

## 제공 화면

- 회원가입·로그인·자동 토큰 갱신·로그아웃. 토큰과 상담 내용을 localStorage/sessionStorage에 넣지 않으며 새로고침 시 다시 로그인한다.
- 사건 목록·생성·상황 수정·삭제. 빈 목록과 페이지 이동을 제공한다.
- 파일 목록·업로드·OCR 사전 동의·인식 결과·사진 관찰 결과·수정본 저장·민감정보 검토 후 확정. 저장하지 않은 수정 내용으로 확정하는 것을 차단한다.
- 현재 브라우저에서 올린 이미지의 로컬 미리보기. 다른 파일과 혼동하지 않도록 파일 ID를 연결하며 확정·사건 이동·로그아웃 시 Blob URL을 폐기한다. 과거 업로드와 PDF의 서버 원본 미리보기는 제공하지 않는다.
- 확정본 선택(현재 첫 100개)·650 UTF-16 단위 발췌 미리보기·사진 관찰 JSON·질문·분석 실행·이력·출처·추가 확인. 요청 키는 응답 불확실 시 재사용하며 실패 기록 확인 후 새 실행으로 진행한다. 관찰은 원인·책임을 확정하지 않는다.
- 이전 분석은 최신 아님을 표시하고 대응 준비 진입을 막는다. 대응 메시지는 사용자 진술·목표·확인 질문을 담은 편집 가능한 기본 양식이다. 검토 체크 후 TXT 다운로드하며 자동 전송하지 않는다.
- 추가 대화 목록·질문·실패한 질문 재시도. 현재 채팅은 사실 정리 전용이며 OCR/RAG를 자동 연결한다고 표시하지 않는다.

`GET /api/v1/cases/{caseId}/files`를 추가했다. 제거된 자료를 제외한 메타데이터를 공통 페이지로 반환하며 소유권을 검증한다. 원본 경로나 OCR 원문은 포함하지 않는다. `/`, `/index.html`, `/assets/**`만 공개하고 기존 데이터 API 인증을 유지한다.

## TDS 디자인 참고

사용자가 지정한 [TDS 공식 컴포넌트 안내](https://developers-apps-in-toss.toss.im/design/components)의 Button, Badge, ListRow, Tab, Top 구성을 참고했다. 개별 상세 문서 링크는 조회 시 응답하지 않아 정확한 컴포넌트 규격 준수를 주장하지 않는다. 파란 주요 버튼, 밝은 중립색, 상태 배지, 일관된 입력·목록·탭, 한 화면의 핵심 행동이 드러나는 구조를 자체 CSS로 구현했다.

앱인토스 전용 TDS SDK·UI Kit·폰트·이미지 자산을 복사하거나 배포하지 않는다. 토스 제품 또는 공식 TDS 구현으로 표시하지 않는다.

## 검증

```powershell
npm ci
npm test
# 최초 브라우저 설치가 필요한 환경
npx playwright-core install chromium
npm run test:ui
.\gradlew.bat test
git diff --check
```

일반 JVM 테스트에는 Node·브라우저가 필요하지 않다. `npm test`는 HTML 이스케이프, 공식 링크 제한, 서버와 같은 유니코드 발췌 경계, 메시지 양식을 검증한다. `test:ui`는 로컬 정적 서버와 고정 API 응답을 사용하는 Chromium 테스트다. 회원가입 → 사건 → 업로드 → OCR 수정·확정 → 분석 → 다운로드, 토큰 재발급, stale, 외부 오류, 로그아웃 및 모바일 가로 넘침을 검사한다. 스크린샷은 Git 제외 경로 `build/ui-smoke`에 저장한다.

브라우저 테스트는 실제 OpenAI 정확도나 서버 전체 E2E를 검증하지 않는다. 실제 DB·보안 필터·소유권·파일·분석·무효화는 별도의 PostgreSQL 통합 테스트로 확인한다. 실제 AI 호출 기록은 별도 평가 문서를 따른다.
