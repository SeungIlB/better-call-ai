# 무료 검증 배포 계획

## 현재 E2E 상태

8085·8087 포트의 새 서버에서 노동·소비자·가사·상속·명예훼손·개인 상해·상거래 시나리오가 각각 업로드, OpenAI OCR, 확정본 저장, 분석 저장, 멱등 재실행, 모바일 화면, 다운로드, stale 처리, 사건 삭제, 로그아웃까지 통과했다. 각 실행 리포트는 `build/live-ui/*/report.json`에 남아 있다.

## 권장 무료 구성

1. **Render Web Service**에 `Dockerfile`로 Spring Boot를 배포한다. 무료 인스턴스는 15분 유휴 후 중지되고 재기동에 약 1분이 걸리며 로컬 파일이 유지되지 않으므로 데모·검증 용도로만 사용한다. [Render 무료 배포 제한](https://render.com/docs/free)
2. **Neon Free PostgreSQL**을 외부 DB로 사용한다. pgvector 확장을 지원하지만 프로젝트 저장공간은 0.5GB 수준이고 비활성 후 자동 중지되므로 법률 코퍼스 전체 적재 전 용량을 확인한다. [Neon 요금·한도](https://neon.com/pricing)
3. Redis는 현재 장애 시 요청 보호를 우회하는 선택적 구성이라 1차 배포에서 제외한다. ClamAV는 업로드 경로에 필요한 TCP 서비스이므로 공개 배포 전 별도 서비스 또는 관리형 악성코드 검사로 연결해야 한다. 무료 데모에서 이를 끄려면 업로드 정책과 보안 고지를 함께 바꿔야 한다.

## 배포 순서

1. Render·Neon 계정을 만들고 Neon 연결 문자열과 pgvector 확장을 준비한다 → `/actuator/health`와 Flyway V001~V025 성공을 확인한다.
2. Render 환경변수에 DB 세 역할 비밀번호, JWT 키, `OPENAI_API_KEY`, `OPENAI_CHAT_MODEL`, OCR 모델, `JWT_ISSUER`/`JWT_AUDIENCE`를 등록한다. 비밀값은 저장소와 이미지에 넣지 않는다.
3. Render에서 Docker 이미지 빌드 후 헬스 체크 경로를 `/actuator/health`로 설정한다. 무료 인스턴스의 콜드 스타트와 OpenAI 90초 분석 지연을 고려해 클라이언트 타임아웃을 설정한다.
4. 배포 URL에서 회원가입 → 사건 → 이미지 업로드 → OCR 확인·수정 → 확정 → 분야별 분석 → 출처·다운로드 흐름을 다시 실행한다. 실제 개인정보 문서는 사용하지 않는다.
5. 상거래 재검증까지 통과한 뒤에만 데모 URL을 공유한다. 공개 전 CORS, 로그, 비용 알림, OpenAI 키 회전과 데이터 삭제를 점검한다.

## 배포 전 차단 조건

- Render 무료 디스크에 원본·업로드를 영구 저장하지 않는다. 현재 확정 OCR은 DB에 저장되지만 임시 원본은 재시작 시 사라질 수 있다.
- ClamAV를 연결하지 않은 공개 업로드는 승인하지 않는다.
- Neon Free의 저장공간·자동 중지·백업 한계 때문에 실제 사용자 개인정보와 대규모 법률 데이터를 운영하지 않는다.
- 결제 화면과 유료 유도는 현재 정책대로 노출하지 않는다.
