# 확정본·검색·초안 생성 연결 평가

2026-09-10 새로운 가상 사례 6개를 기존 서비스 코드로 평가했다. **서버 응답은 6/6 통과했지만 선정 목표 조문은 2/4만 검색됐고, 생성 설명에서 시행일 오판이 발견됐다. 품질 통과로 판단하지 않는다.** 평가 결과를 보고 검색 규칙이나 프롬프트를 바꾸지 않은 최초 실행 기록이다.

## 범위와 실행

```powershell
.\gradlew.bat importLegalData --args=flow-evaluate
```

기존 `draft-evaluate`는 제공 조문 2개를 고정하지만, 이번 명령은 로컬 DB에 가상 사용자·사건·확정 OCR 수정본을 만든다. 실제 `LegalDraftServiceImpl` → `CaseEvidenceSearchServiceImpl` → `LegalEvidenceSearchServiceImpl` 흐름으로 현재 확정본 조회, 650자 발췌, 용어 보완, 실제 임베딩, PostgreSQL 검색, 실제 생성과 출처 검증, 사건 버전·수정본 재확인을 실행한다. 검색 결과를 기록하는 래퍼는 검색을 한 번만 호출하고 반환 결과를 변경하지 않는다.

`.env`의 `DATABASE_URL`, `DATABASE_MIGRATION_USER/PASSWORD`, `DATABASE_APP_USER/PASSWORD`, `OPENAI_API_KEY`가 필요하다. 기존 명령과 동일하게 로컬 포트 5433의 `legal_ai` DB만 허용하며 운영 명령 잠금을 공유한다. 준비·정리는 migration 계정으로, 실제 서비스 조회는 RLS를 우회하지 않는 app 계정으로 실행한다. 실행별 임의 UUID로 생성한 가상 사용자와 그 사건만 `finally`에서 정리한다. 강제 프로세스 종료로 정리가 실행되지 않은 경우 로컬 보고서의 `fixtureOwner`로 잔여 평가 데이터를 식별할 수 있다.

가상 수정본은 DB에 직접 준비하므로 **OCR 인식, 사용자 확정 API, 파일 업로드, HTTP/JWT 인증을 포함한 전체 시스템 E2E는 아니다.** 서비스의 인증 사용자 컨텍스트를 직접 설정하며 기존 컨텍스트는 복구한다. 이 영역의 정상·인가 실패·버전 충돌은 기존 자동 테스트와 구분한다.

호출 전에 사례, 질문, 발췌 시작점, 목표 조문, 검토 기준을 `build/legal-flow-evaluation/<timestamp>/examples.json`에 저장한다. 보고서에는 실제 검색 결과·보완 검색어·응답·시간·오류 코드와 코퍼스·검색 규칙·생성 구현 해시를 기록한다. `completed`는 전체 실행 완료, `acceptedByServer`는 서버 검증 통과, `fixturesCleaned`는 정리 트랜잭션 완료다. 법률 정확도를 자동 판정하지 않으며 원시 보고서의 `manualReview=pending`과 별도로 아래 개발 에이전트 관찰을 기록했다. 법률 전문가 검토는 받지 않았다.

실제 API 호출이므로 비용이 발생한다. 이번에는 임베딩 6회와 생성 6회를 호출했으며 자동 재시도는 없다. 일반 `test`와 앱 기동 시 실행하지 않는다. 생성 설정은 기존 평가와 같은 `gpt-5.6-sol`, `none`, 1200토큰, 40초이며 `DRAFT_EVAL_*`로 변경할 수 있다. 앱의 `OPENAI_CHAT_*`나 로컬 비밀 설정은 변경하지 않았다. 임베딩은 `text-embedding-3-small`이다.

보증금 사례에서 제시한 출처의 시행일은 2026-01-02이며 평가일은 2026-09-10이다. 장래라는 설명은 틀렸다. 생성 입력은 조문 시행일을 포함하지만 현재 기준일은 제공하지 않는다. 이것은 가능한 원인이지 검증된 인과관계는 아니다. 정확한 인용문과 공식 링크 검증만으로 설명의 시간 판단 오류가 차단되지 않음을 확인했다.

검색 누락 두 건 모두 관련 용어가 추가되지 않았다. 보증금 사례는 `HousingSearchTerms`의 첫 주거 표현 검사에서 걸렸고, 방 사용 불가 사례는 `쓰지 못한`·`사용하지 못한다`가 현재 불가 표현 목록과 일치하지 않았다. 검색 누락과 규칙 미작동을 관찰했지만, 표현 추가만으로 적중이 개선되는지는 아직 재평가하지 않았다.
